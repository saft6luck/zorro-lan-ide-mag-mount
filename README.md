# zorro-lan-ide-mag-mount
MagFix: PCB &amp; 3D-Printed Holder for Matze's Zorro-LAN-IDE Card https://gitlab.com/MHeinrichs/Zorro-LAN-IDE
which also works for A4000D+ boards with integrated Ethernet controller.

The MagJack(TM) (e.g. SI-50170-F) version will hardly fit into the normal Zorro extension openings. The 3D model can be used to mount the MagJack(TM) version to the Expansion opening of the A4000 remake case.
